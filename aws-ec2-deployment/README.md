# 🚀 AWS EC2 Deployment and Secure SSH Access

## 📌 Project Overview

This project demonstrates the deployment of a virtual server on AWS EC2 and secure access via SSH.
A web server was configured using Apache, and a custom webpage was successfully hosted and accessed over the internet.

---

## ⚙️ Implementation Summary

* Launched EC2 instance (Amazon Linux)
* Configured security groups (SSH – Port 22, HTTP – Port 80)
* Connected securely via SSH (EC2 Instance Connect)
* Installed and configured Apache HTTP Server
* Deployed a custom HTML webpage
* Verified deployment via public IP
* Performed resource cleanup to avoid billing

---

## 🌐 Output

A live web server hosted on AWS EC2 and accessible via public IP.

---

## 🧠 Key Skills Demonstrated

* AWS EC2 (Infrastructure as a Service)

* Web Server Deployment (Apache)
